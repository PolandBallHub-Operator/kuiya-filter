### クイヤフィルター (Quiya Filter) 
**「最近、家の外にFOSSのクイヤが大量発生し、MITだなと感じます」**
<br>**「あぁ〜クイヤね。千葉とかに住んでた時にあった気がする」**

**クイヤフィルター**は、ウェブ閲覧中に突如現れる不快な言葉や画像を、みんなが大好きな謎の（実在する？）害獣「クイヤ」の表現にマイルドに置き換える、Android向けのオープンソース（FOSS）コンテンツモディファイアプリです。

PC,iPhoneブラウザ向け拡張機能「ひよこフィルター」にインスパイアされ、「Android版がないならクイヤで作ればいいじゃない」という強い意志（と幻覚）から代替アプリとして開発しました。

###  主な機能

### 1. 画像のフィルタリング・ブロック（尻尾もある）

* ウェブページ内の不快な画像を自動的にブロック。モルモットやビーバーに似ていて**「尻尾もある」**かわいいクイヤ（**🦫**）に置換します。

### 2. テキスト置換（クイヤ化）

* 嫌なキーワードやミュートしたい単語を、自動的に「クイヤ」などの指定表現に置き換えます。
* **「数字の9」**を極端に嫌うクイヤの習性に習い、「9」に関する不快なテキストも自動でクイヤ化可能です。

### 3. 高度なカスタムワード設定（Winメモ帳スタイル）

設定画面の自由なテキスト入力欄に、Windowsのメモ帳のように1行ずつルールを記述するだけで、自由なカスタム置換が可能です。

 

* **記述例:** 疲れた<ky>睡眠30min
* **動作例:** 

  * 元のウェブ表記：「**疲れた**なら寝るべき」
  * 置換後の表記：「**睡眠30min**なら寝るべき」
* **応用例（ダンベルたたきつけモード）:** 害獣<ky>ダンベルたたきつけ と設定すれば、ウェブ上の害獣被害ニュースがすべてパワフルなパワー系撃退ログへと変貌します。


### 4. URLブロッカー（よかったなこの距離で）

* 指定した特定のURLやドメインへのアクセスを強制的にブロックし、閲覧を制限します。
* ブロック画面には**「よかったなこの距離で」**という警告メッセージが表示され、有害サイトとのディスタンスを安全に保ったことを知らせてくれます。

###  UI/UX デザイン

### Duet-style UI

片手での操作性を重視した、モダンな2段構成のインターフェースを採用しています。 

* **画面下部（ボトムバー）：** 戻る / 進む / 共有 / ホーム ボタンを配置。
* **画面上部（トップバー）：** シンプルなURL表示バーのみを配置。

### Material You & Monet 対応

* Googleの最新デザイン系统「Material You」に完全準拠。
* デバイスの壁紙に合わせた動的カラーテーマ（Monet）のオン/オフを自由に切り替え可能です。

 **注意:** 本アプリはChromeなどの外部ブラウザから「ページを共有」して開くための**フィルター専用ビューア**です。フルブラウザではないため、タブ管理、ブックマーク、ダウンロードなどの機能は搭載していません。
